# KM4BE Satellite Info 0.10.0

Passes you would otherwise miss.

## New

- **Pass alerts.** Turn on Pass alerts in the panel's settings and the line under the call info tells you a few minutes before a satellite rises: "AO-7 rises in 2 min in the NNE, up to 62°". While it is up the line says where it is and when it sets, and it goes away when it sets. Alerts come even with the panel closed.
- **Favorites only.** A second setting limits the alerts to the satellites you have starred.
- **How early.** Choose how many minutes before rise an alert appears, from 1 to 30. The default is 3.

## Good to know

- At most three alerts show at once, soonest first, so the line keeps room for anything else.
- Dismiss an alert and it stays down for a few minutes.
- The alerts use the panel's minimum elevation and grid square. Change them in the panel and the alerts follow.

## Still true from 0.9.0

- Logging contacts via the satellite, rotator tracking, Doppler tracking, the Map tab and smoother live updates.
- Needs a Ham2K Logger that speaks extension API 25 or later.
