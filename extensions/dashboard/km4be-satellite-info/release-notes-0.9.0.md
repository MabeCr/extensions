# KM4BE Satellite Info 0.9.0

Contacts know which satellite they went through.

## New

- **Log contacts via this satellite.** A switch on a pass's Radio page puts the satellite on the contact you are typing, and on every contact you start during the pass and for five minutes after it sets. It uses the same satellite reference as Ham2K's Satellites activity, so your logs and ADIF exports carry SAT_NAME and PROP_MODE, without typing SAT in the call field. The contact's other references, such as a park, stay as they are.

## Good to know

- Installing this version asks to change the contact you are typing. It does so only while the switch is on.

## Still true from 0.8.0

- Rotator tracking, Doppler tracking, the Map tab and smoother live updates.
- Needs a Ham2K Logger that speaks extension API 25 or later.
